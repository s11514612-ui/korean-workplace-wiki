SECTION 01 · GRAMMAR

核心敬語文法解析

韓語職場溝通常見的敬語，主要會出現在句尾、主體尊敬表現，以及對他人行為的謙讓表達。以下整理常用句型與使用時機。

句尾敬語

-습니다 / -ㅂ니다

正式、較有距離感，常用於簡報、正式報告或初次聯繫。

日常禮貌體

-아요 / -어요

職場日常對話常見，語氣自然且有禮貌。

主體尊敬

-(으)시-

尊敬句子的主體，例如主管、客戶或長輩。

常見敬語文法對比表

可左右滑動
文法／片語中文說明適用時機語氣／敬語階級
-습니다 / -ㅂ니다正式陳述句尾，語氣端正。正式簡報、會議報告、公告。正式敬語體（하십시오체）
-아요 / -어요日常禮貌句尾，較自然親切。同事日常交談、一般工作詢問。非正式禮貌體（해요체）
-(으)시-尊敬句子的主體，接在動詞或形容詞詞幹後。描述主管、客戶或長輩的動作與狀態。主體尊敬法
께서主格助詞「이/가」的尊敬形式。尊敬對象作為句子主語時。主體尊敬
드리다「주다」的謙讓語，表示自己為對方做某事。向主管或客戶提供資料、協助。謙讓表現
말씀하시다「말하다」的尊敬表現，表示對方說話。轉述主管、客戶或長輩的發言。詞彙型尊敬
죄송합니다正式道歉，比 미안해요 更正式。工作延誤、造成不便或需要致歉時。正式禮貌表現
확인 부탁드립니다敬請確認；以 부탁드리다 表達謙讓請託。Email、工作訊息請對方確認資料。正式商務表現

GRAMMAR IN CONTEXT

句型拆解｜請對方確認資料

正式敬語體

情境：寄送文件給主管或合作窗口，希望對方協助確認內容。

첨부 파일을 확인해 주시면 감사하겠습니다.

如果您能幫忙確認附件，我將非常感謝。

文法點中文解釋適用對象
첨부 파일附件、附加檔案。同事、主管、客戶皆可。
확인해 주시다請對方幫忙確認；주다 搭配 -(으)시- 表達對對方動作的尊敬。需要對方協助執行動作時。
-(으)면 감사하겠습니다「如果……我會很感謝」，比直接命令更委婉。正式 Email 或較客氣的請託。
使用提醒：「확인해 주시면 감사하겠습니다」已經是自然且有禮貌的請託。避免再疊加不必要的尊敬形式，像是不自然地使用雙重敬語。

SECTION 02 · SCENARIOS

情境對話範本｜Email vs 口語

同一個溝通目的，會因為媒介和對象不同而改變語氣。點選下方分類查看範本，並可直接複製韓語內容。

情境 A · 寄送資料

寄送會議資料給主管

안녕하세요, 팀장님.

요청하신 회의 자료를 첨부하여 보내드립니다.
확인 부탁드립니다.

감사합니다.
홍길동 드림.

中文理解：您好，組長。隨信附上您要求的會議資料，敬請確認。謝謝您。洪吉童敬上。

用法：드림 是常見的書信結尾敬語；팀장님 是對組長的稱呼。

情境 B · 請求確認

詢問對方是否方便確認

검토해 보시고 의견 주시면 감사하겠습니다.

中文理解：若您看過後能提供意見，我將非常感謝。

用法：適合正式 Email；不是命令對方，而是委婉提出請求。

EMAIL · 書面

資訊完整、語氣較正式

通常包含問候、說明目的、具體請求與結尾。第一次聯繫或對外窗口，建議使用較完整的格式。

SPOKEN · 口語

簡潔自然、仍保有禮貌

面對面或即時訊息可更精簡，但對主管、客戶仍建議使用 해요체 或正式敬語體。

SECTION 03 · AI REFLECTION AGENT

AI Reflection Agent 運作機制

Reflection Agent 不只一次產生答案，而是把「撰寫、檢查、修正」拆成不同階段。透過反覆檢視，降低敬語使用錯誤、語氣不自然或文化情境不合適的機率。

01 · WRITER✎

Writer

初步生成

依照使用者提供的情境、對象與目的，產生韓語句子或職場訊息初稿。

輸入：寄信給主管，請對方確認報告。
→
02 · REVIEWER⌕

Reviewer

檢查與反思

檢查文法、敬語階級、稱謂、語氣自然度，以及是否出現不合理的雙重敬語。

檢查：對象是否合適？表達是否自然？
→
03 · REVISION↻

Revision

修正與輸出

依照檢查意見調整句子，保留原本意思，輸出較正確、自然且符合情境的版本。

輸出：修正版＋修改原因。
↺

反思迴圈：若 Reviewer 判定仍有問題，Revision 可再次交由 Reviewer 檢查；達到品質標準後才輸出最終版本。

Reviewer 檢查清單

  • ✓ 文法與助詞是否正確
  • ✓ 敬語階級是否符合收件者
  • ✓ 稱謂與主體尊敬是否恰當
  • ✓ 是否出現重複或不自然的敬語
  • ✓ 語氣是否符合職場文化與情境

預期輸出內容

  • ✓ 修正後的韓語句子
  • ✓ 對應的繁體中文翻譯
  • ✓ 修改位置與原因
  • ✓ 敬語階級與適用情境
  • ✓ 必要時提供更自然的替代說法

IMPORTANT NOTE

AI 產出仍需要人工確認

Reflection Agent 能協助檢查與改善內容，但不代表每次都能完全理解公司內部文化、職稱習慣或人際關係。正式寄出前，仍應由使用者依實際情況確認。

SECTION 04 · ETIQUETTE

韓國職場社交與禮儀

語言之外，稱呼、回應方式與職場互動也會影響溝通給人的感受。以下是初入韓國職場時可以先掌握的基本原則。

🙇

稱呼與職稱

不確定對方偏好時，可先使用職稱加 님，例如 팀장님。避免未熟識就直呼名字或擅自使用過度親暱的稱呼。

🤝

初次見面

以簡單問候和自我介紹開場。握手或鞠躬的方式會因公司與情境不同，觀察對方並自然回應即可。

📩

訊息與 Email

訊息盡量說明目的、期限與附件；收到工作指示時，簡短回覆已收到或預計完成時間，避免讓對方不確定進度。

🍵

聚餐與日常互動

聚餐場合可能有較多職場文化差異，不必假設所有公司都遵循相同規矩。尊重個人選擇、飲食需求與界線最重要。
